Playwright MCP 的默认超时:动作 5 秒,导航 60 秒

标签:MCP、超时

Playwright MCP 有两个最容易搞混的超时:动作超时和导航超时。它们管的事情完全不同,调参时不能混着改。

两个默认值

动作超时默认 5000 毫秒,管的是单个动作等元素就绪的时间,比如点击一个还没变成可点击状态的按钮。对应参数是 --timeout-action。导航超时默认 60000 毫秒,管的是一次页面跳转从发起到加载完成的时间,对应参数是 --timeout-navigation。两者单位都是毫秒。

超时之后会发生什么

超时不会静默继续,而是抛出一个带具体数值的错误,形如 "Timeout 15000ms exceeded"。这个数值就是当前生效的配置值,所以它是验证超时参数有没有生效的最直接证据。看到 5000 说明还在用默认值,看到你配置的数字说明参数生效了。

什么时候该调

本地练习站几乎不需要调,默认值足够。但如果目标站点首屏要拉很多静态资源,60 秒可能不够,这时才把导航超时调到 90000 或 120000。反过来,动作超时调太大会让一次失败拖很久,影响整体任务节奏。

不要做的事

把超时设成 0 或无限,等于放弃了"失败要停"这个约束。任务卡住时,无限等待比报错更难排查,因为你分不清是在等、还是在坏。
